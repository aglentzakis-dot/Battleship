# Ναυμαχία 3Δ · Battleship 3D

Ναυμαχία σε τρία επίπεδα — **αέρας, επιφάνεια, βυθός** — με υποβρύχιο που κρύβεται στα βάθη, αεροσκάφη που γίνονται πιο επικίνδυνα όσο πλησιάζουν, νάρκες και μεταβαλλόμενο καιρό.
Παίζεται εναντίον του υπολογιστή ή με δύο παίκτες στην ίδια συσκευή. Δίγλωσσο: ελληνικά / αγγλικά, με κουμπί αλλαγής πάνω δεξιά.

## Ανέβασμα στο GitHub

1. Άνοιξε το <https://github.com/aglentzakis-dot/Battleship/upload>
2. Σύρε μέσα **όλα** τα αρχεία του φακέλου (χωρίς υποφακέλους):
   - `index.html` — το παιχνίδι
   - `manifest.json` — τα στοιχεία της εφαρμογής
   - `sw.js` — για να παίζει και χωρίς ίντερνετ
   - `icon-192.png`, `icon-512.png`, `icon-512-maskable.png`, `apple-touch-icon.png` — εικονίδια
   - `README.md` — αυτό εδώ
3. Πάτα **Commit changes**.

## Ενεργοποίηση της σελίδας

Settings → Pages → Source: **Deploy from a branch** → Branch: **main** / folder: **/ (root)** → Save.

Σε 1–2 λεπτά το παιχνίδι είναι στο:

```
https://aglentzakis-dot.github.io/Battleship/
```

## Εγκατάσταση στο κινητό

- **Android / Chrome:** άνοιξε τη διεύθυνση → μενού ⋮ → «Εγκατάσταση εφαρμογής» (ή το κουμπί ΕΓΚΑΤΑΣΤΑΣΗ μέσα στο παιχνίδι).
- **iPhone / Safari:** Κοινή χρήση → «Προσθήκη στην οθόνη Αφετηρίας».

Μετά την πρώτη φόρτωση παίζει και χωρίς σύνδεση.

## Όταν αλλάζουμε κάτι

Το `sw.js` κρατά αντίγραφο στο κινητό. Κάθε φορά που ανεβάζεις νέο `index.html`, άλλαξε και τη γραμμή:

```js
const CACHE = 'naumachia3d-v3';
```

σε `v4`, `v5` κ.λπ., αλλιώς τα κινητά που το έχουν ήδη εγκαταστήσει θα συνεχίσουν να δείχνουν την παλιά έκδοση.

## Τι έχει το παιχνίδι

- **Τρία επίπεδα:** αέρας, επιφάνεια, βυθός — το υποβρύχιο μπορεί να περάσει κάτω από πλοίο.
- **Ελιγμός υποβρυχίου** κάθε γύρο: ή αλλαγή βάθους ή μετακίνηση ένα τετράγωνο.
- **Βάθη:** 15μ (τορπίλες, αλλά το κανόνι το βρίσκει 50%), 120μ, 300μ (θερμοκλινές — το σόναρ ακούει λάθος).
- **Νάρκες:** τρεις ανά πλευρά· όποιος τις χτυπήσει χάνει τον επόμενο γύρο.
- **Ικανότητες ανά πλοίο:** αεροπλανοφόρο → αεροσκάφη, φρεγάτα → σόναρ και αντιαεροπορικά, αντιτορπιλικό → βόμβες βυθού, πυραυλάκατος → διπλή ριπή, υποβρύχιο → τορπίλες.
- **Καιρός** που αλλάζει κάθε 4 γύρους: γαλήνη, φουρτούνα, ομίχλη, ρεύματα.
- **Ήχοι** (με διακόπτη), δόνηση, ημερολόγιο γέφυρας, βαθμοί και ρεκόρ.

Τα δεδομένα (ρεκόρ, γλώσσα, ήχος) μένουν μόνο στη συσκευή σου.
